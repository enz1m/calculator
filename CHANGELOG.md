# Changelog

## 0.1.3

- The Calculator window can appear without waiting for display setup on Wayland.
- Opening and closing the sidebar is smoother, making it easier to switch between a calculation and your history.

## 0.1.0 — initial preview

- Basic and scientific expressions with live results and reusable history.
- Unit conversion, session memory and degree/radian modes.
- enzUI Alpha 0.1, native window controls, themes, keyboard navigation and text transfers.
- English, German and Arabic interfaces.
- Compact gallery with default and customized app screenshots.
